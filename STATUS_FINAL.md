## 📱 FLUJO DE PRUEBA (5 MINUTOS)

```
1. Abre Android Studio (npx cap open android)
   └─ Espera Gradle (2-5 min)

2. Selecciona Device Manager
   └─ Emulador recomendado
   └─ O conecta dispositivo físico con USB

3. Ejecuta (Shift+F10 o Run → Run 'app')
   └─ App se instala y corre

4. Crea tarea de prueba:
   - Título: "Prueba"
   - Fecha: Today + 3 minutos
   - Notificar: 1 minuto antes
   - Prioridad: Alta
   
5. Guarda y espera...
   └─ A los 2 minutos: ¡VES LA NOTIFICACIÓN!

6. Verifica logs:
   - View → Tool Windows → Logcat
   - Filter: "NotificationService"
   - Deberías ver: "✅ Notificación programada..."
```

## 💡 TIPS IMPORTANTES

### Emulador vs Dispositivo Físico
```
EMULADOR:
✅ Rápido para desarrollo
✅ Fácil debugging
❌ Requiere Google Play Services

DISPOSITIVO:
✅ Test real y completo
✅ Mismo comportamiento de producción
❌ Requiere USB configurado
```

### Si las Notificaciones No Funcionan
```
1. Verifica Logcat (View → Tool Windows → Logcat)
2. Filtra por "Notification"
3. Si dice "Fecha ya pasó": crea en futuro
4. Si dice error: revisa permisos con adb
5. Si vacío: limpia build y reinstala
```

### Logging para Debugging
```
Android Studio Logcat:
├─ Filter: "NotificationService"
├─ Nivel: Verbose o Debug
└─ Verás cada acción en tiempo real

Ejemplo de logs esperados:
✅ Notificación programada para tarea 1 a las...
❌ Notificación cancelada para tarea 1
🔄 Reprogramando todas las notificaciones...
```
